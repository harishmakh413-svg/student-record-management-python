
# Student Record Management System

## Project Description
This is a simple Student Record Management System developed using Python. It allows users to manage student records through a menu-driven program.

## Features
- Add student records
- Display all student records
- Search for a student
- Update student details
- Delete student records
- Input validation and exception handling

## Technologies Used
- Python
- Jupyter Notebook

## Project Files
- student_management.py
- student_management.ipynb

## How to Run
1. Open the Python file or Jupyter Notebook.
2. Run the program.
3. Select the required option from the menu.
